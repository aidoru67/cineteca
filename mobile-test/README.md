# Cineteca v1.2-mobile.3

Responsive mobile/public frontend for La Mia Cineteca.

## Important
This build is designed to work both:
- on GitHub Pages (`https://...`), and
- locally by opening `index.html` directly (`file://...`).

The public catalog connects directly to the existing Supabase REST API. No local server is required.

## Test
1. Extract the ZIP.
2. Double-click `index.html`.
3. Wait for the catalog to load.
4. Test search, Generi, DVD, Saghe, Casuale, Filtri and a film detail.

No Supabase/database changes are required for this frontend build.
